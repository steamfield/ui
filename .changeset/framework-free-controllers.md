Move each stateful component's logic into one framework-free controller that the React and Vue bindings adapt: the agent demo (timeline, playback clock, step starts, end detection, controls), the playback gate's element binding, tabs selection and copy state. Public exports, props and markup are unchanged. A remount of `usePlayback`, `useCountUp` or the agent demo (React StrictMode, `<Activity>` hide and show) now resumes where it was instead of starting over, without firing `onStepStart` or `onComplete` again, and a `setSpeed` rate holds until the `speed` option changes. A throwing `onStepStart` or `onComplete` no longer stops the clock or skips later callbacks; every error is rethrown after the rest run (an `AggregateError` for several), and one thrown during a prop update or a mount is rethrown from a microtask instead of unwinding the render. Two visible fixes come with it: a React `Tabs` `defaultValue` naming a disabled or unknown tab now falls back to the first enabled tab after hydration, as `createTabs` already did; and markdown code-block copy wrappers now also carry `data-copy-root`, the same marker `CopyButton` uses.
